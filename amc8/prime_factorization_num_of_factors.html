📚 How to Find the Number of Factors

First write the number in prime factorization form:

n = ax × by × cz

where a, b, c are prime numbers.

Then add 1 to each exponent and multiply:

Number of Factors = (x + 1)(y + 1)(z + 1)

✔ A factor divides the number exactly.

✔ Prime factorization breaks a number into prime numbers only.

✔ Example:

36 = 2² × 3²

Number of factors = (2+1)(2+1) = 9
